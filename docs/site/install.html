Install and use

One command installs Shentu and starts a guided setup with five questions:

curl -fsSL https://github.com/nt-neil/shentu/releases/latest/download/install.sh | sudo sh
  1. language (English or 繁體中文);
  2. the AI model (a local model, or an API key), tested once;
  3. where alerts go (Telegram, Slack, Discord or ntfy), with a test message;
  4. a survey of the server, with the risks it finds;
  5. patrols on, plus an optional first report.

Then ask questions with sudo shentu chat. Run sudo shentu setup again to change anything.

Commands

  • shentu chat: ask about your server's security in plain language; the model chooses which tools to run and explains what it found.
  • shentu patrol: run by a systemd timer every 30 minutes, with fixed checks that include the audit of the web applications' code. New findings are explained by the LLM and sent to your notification channel; if the LLM is down, you still get the raw findings.
  • shentu survey: learns the server first, as the baseline for patrols.
  • shentu bot (optional): talk to Shentu from Telegram, with levels you choose; notifications only by default.

Supported systems

Ubuntu 22.04 and 24.04, Debian 12, Rocky and Alma 9, on amd64 and arm64 (systemd is required). Each release carries .deb and .rpm packages and a signed build provenance you can check with gh attestation verify.

It never changes the system on its own: every action that changes something waits for a human to confirm it. Step by step: Getting started.
