PHP Command injection

極criticalphp-cmdi-mail-params CWE-88Request data in the fifth (additional_params) argument of mail()

Frameworks: laravel

Reported

<?php
$from = $_POST['from'];
mail('sales@example.com', 'Contact form', $_POST['message'], '', '-f' . $from);

Fixed

<?php
ini_set('sendmail_from', 'noreply@example.com');
mail('sales@example.com', 'Contact form', $_POST['message'], 'Reply-To: noreply@example.com');

Fix Leave mail()'s fifth argument out (set sendmail_from in php.ini or with ini_set) or pass only a fixed value; escapeshellarg does not help here because mail() escapes the argument again.

極criticalphp-cmdi-shell-exec CWE-78Request data (including headers) placed into a shell command

Frameworks: laravel

Reported

the Host header is attacker-controlled

<?php
$host = $request->getHost();
exec("curl -s https://stats.example.com/ping?site=" . $host . " > /dev/null 2>&1 &");

Fixed

<?php
$ip = filter_var($_GET['ip'], FILTER_VALIDATE_IP);
if ($ip !== false) {
    echo shell_exec('ping -c 1 ' . escapeshellarg($ip));
}

Fix Avoid the shell: use a PHP function or an argument array (proc_open with an array, Symfony Process); if a shell is unavoidable, wrap every value in escapeshellarg().

Fixed

Reported

Fixed

public function index(Request $request)
{
    $sort = $request->input('sort', 'created_at');

Fixed

Fix Identifiers cannot be bound as parameters: map the requested sort key to a fixed allowlist of column names and force the direction to ASC or DESC.
