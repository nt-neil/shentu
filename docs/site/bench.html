Measured on real vulnerabilities

The rules are run on the last vulnerable and the first fixed release of published vulnerabilities (CVE.org, NVD, GitHub Advisory, OSV). A case counts as caught when a rule of its class reports within 10 lines of the code the fix changed; a fixed false positive is a rule that still reports there after the fix. The numbers are generated from the bench results, not written by hand.
