安裝與使用

一行指令安裝，並啟動五個問題的引導設定：

curl -fsSL https://github.com/nt-neil/shentu/releases/latest/download/install.sh | sudo sh
  1. 語言（English 或繁體中文）；
  2. AI 模型（本機模型或 API 金鑰），會測試一次；
  3. 警示要送到哪裡（Telegram、Slack、Discord 或 ntfy），並送出測試訊息；
  4. 盤點伺服器，列出發現的風險；
  5. 開啟巡邏，可選擇先產出第一份報告。

之後用 sudo shentu chat 直接用白話提問；要改設定就再跑一次 sudo shentu setup。

主要指令

  • shentu chat：用白話問伺服器的資安狀況，模型自己挑工具執行並說明結果。
  • shentu patrol：由 systemd timer 每 30 分鐘執行固定檢查，包括稽核網站應用程式的原始碼；有新發現時，由 LLM 說明後送到通知管道。LLM 掛了也照樣送出原始發現。
  • shentu survey：先認識伺服器，當作巡邏的基準。
  • shentu bot（選用）：從 Telegram 跟 Shentu 對話，權限分級、預設只收通知。

支援的系統

Ubuntu 22.04、24.04，Debian 12，Rocky 與 Alma 9，amd64 與 arm64（需要 systemd）。每個 release 附 .deb 與 .rpm，以及可用 gh attestation verify 驗證的簽章建置來源。

它不會自己改動系統：每個會改變系統的動作都要人確認。詳細步驟見入門指南。
