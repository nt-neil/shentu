框架: laravel

會報出

修正後

修正後

app.get("/continue", (req, res) => {
  res.send('<a href="/start?next=' + encodeURIComponent(req.query.next) + '">Continue</a>');
});

修法 In an href or src accept only http(s) URLs (new URL(value) and a protocol check) or encode the value with encodeURIComponent() after a fixed path; inside <script> serialize it with a script-safe encoder, not with HTML escaping.
